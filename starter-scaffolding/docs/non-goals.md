# Non-goals

Tangle is intentionally not trying to become any of the following yet:

- an autonomous software engineer;
- a general agent or swarm framework;
- a task manager or workflow engine;
- a Harbour integration;
- a production service;
- a parallel worker system;
- a semantic knowledge base or vector-search layer;
- a verification or debate framework;
- a model router or escalation system;
- a self-improving system;
- a system that hides, repairs, or normalises strange experimental behaviour;
- a complete theory of nodes, leaves, evidence, contradictions, or completion.

These are boundaries on the current experiment, not claims that the ideas are permanently undesirable.

The first meaningful milestone is only:

> Grow and persist one inspectable understanding graph from one repository and one seed.
