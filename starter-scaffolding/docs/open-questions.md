# Open Research Questions

These are variables Tangle exists to observe. They are not missing requirements to answer in advance.

- What does a node naturally need to contain?
- Is the resulting structure a tree, a DAG, a graph, or something else?
- What naturally constitutes a leaf?
- When can a node resolve directly from inspected evidence?
- How often are parents revisited before they settle?
- Do nodes need explicit types, or do recurring forms emerge without them?
- How should contradictions appear and propagate?
- What does `blocked` mean in practice?
- Do duplicate or near-duplicate questions materially harm a run?
- Does node-selection order materially change the resulting graph?
- How much local context does a node actually need?
- Which evidence references are useful enough to preserve?
- Do repeated runs over the same repository converge structurally?
- Does structural convergence survive changes in seed wording or model?
- Where does useful decomposition stop naturally?
- What failure modes recur often enough to justify changing the harness?

When an experiment suggests an answer, record the observation in that experiment first. Change the system only after the behaviour is sufficiently repeatable to warrant it.
